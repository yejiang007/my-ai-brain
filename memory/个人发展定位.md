
# 我的个人发展定位

## 一句话定位

以影视创作、直播技术、网站系统和AI能力为基础，研究并实践影视科技融合与产业数字化。

## 我的智库主要研究什么

1. 时光剪影现有业务如何提高利润和竞争力。
2. LY7站群如何持续获得有效客户。
3. 哪些AI系统值得继续开发并对外收费。
4. AI微剧、AI音乐如何形成可销售的商业产品。
5. 我个人应该把时间投入哪些最重要的事情。

## 我的三年方向

- 继续巩固影视制作、活动直播和摄影摄像基本盘。
- 将成熟业务逐步标准化、产品化。
- 优先完善已经拥有客户需求的AI系统。
- 验证AI微剧和AI音乐的商业模式。
- 沉淀案例、方法、数据和个人品牌内容。

## 我暂时不做什么

- 不因为技术热门就盲目开发新系统。
- 不同时推进过多新业务。
- 不在没有客户验证前进行大额投入。
- 不只收藏资料而不采取行动。
- 不为了建智库而影响正常业务和交付。

## 重要决策原则

1. 先研究真实客户是否愿意付钱。
2. 先小成本验证，再扩大投入。
3. 优先利用现有团队、案例、系统和客户资源。
4. 每个新项目必须明确负责人、预算和停止条件。
5. 每月复盘一次，根据事实调整方向。

## 当前最需要智库回答的问题

未来一年，我应该重点投入哪一个方向，才能既发挥现有优势，又形成持续增长？
